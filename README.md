# تطبيق حفظ سورة النساء

تطبيق ويب تقدّمي (PWA) لحفظ سورة النساء مقسّمة إلى **12 مقطعًا موضوعيًّا**، مع:

- مقدمة تعريفية: **الفضل، الأسماء، المقاصد، وعدد الآيات حسب مدارس عدّ الآي الخمس** (المكي، المدني، البصري، الكوفي، الشامي).
- شاشة **موضوعات** تعرض كل مقطع مع نطاق آياته ونص موجز عن مضمونه.
- شاشة حفظ لكل مقطع: تعرض نص الآيات (رواية حفص، رسم عثماني) حيًّا من مصدر موثوق، مع **أيقونة "تعليم كمحفوظ"**.
- نظام **مراجعة تلقائي بمرحلتين**: مراجعة قريبة (1، 3، 7 أيام) ثم مراجعة بعيدة (14، 30، 60، 120، 180 يومًا)، مع لوحة يومية تعرض كل ما هو مستحق اليوم.
- شاشة **متشابهات**: تعرض لكل مقطع الآيات المتشابهة معه سواء داخل سورة النساء نفسها أو مع بقية سور القرآن، معتمدة على قاعدة بيانات مفتوحة مخصّصة لهذا الغرض.
- يعمل offline بعد أول تحميل (Service Worker)، ويمكن تثبيته على الهاتف كتطبيق (PWA).

## ملاحظات مهمة حول دقة المحتوى

1. **التقسيم الموضوعي (12 مقطعًا) اجتهادي** لغرض الحفظ والتنظيم، وليس تقسيمًا توقيفيًّا مجمعًا عليه؛ راجعه إن أردت مطابقته لتقسيم شيخك أو منهج حلقتك، ويمكن تعديله بسهولة من ملف `js/data/topics.js`.
2. **نص الآيات المعروض هو برواية حفص عن عاصم** لأن مصادر البيانات المفتوحة والموثوقة للنص القرآني الرقمي بهذه الرواية هي الأشهر والأكثر توفرًا. ترقيم الآيات (176 آية، العدّ الكوفي) يطابق طبعات ورش المتداولة في الجزائر، لكن **يُنصح بأن يكون الحفظ الفعلي من مصحف ورش المعتمد لديكم**، والتطبيق هنا أداة تتبّع وتنظيم للحفظ والمراجعة، لا بديلاً عن المصحف.
3. **بيانات المتشابهات** مأخوذة من مشروع مفتوح المصدر (`Quran_Mutashabihat_Data`) مخصّص لأشهر المواضع التي تُلبس على الحفّاظ، وليست حصرًا لكل تشابه لفظي ممكن في القرآن.
4. جميع الأرقام والنصوص تُجلب حيًّا من واجهتين برمجيتين مجانيتين (`alquran.cloud` لنص القرآن، و GitHub لبيانات المتشابهات) عند تشغيل التطبيق، ولا تُخزَّن نصوص قرآنية داخل كود المشروع نفسه؛ هذا يضمن دقة النص ومطابقته للمصدر دائمًا.

## هيكل المشروع

```
nisa-app/
├── index.html          نقطة الدخول
├── manifest.json        بيانات تثبيت PWA
├── sw.js                 Service Worker (عمل بلا اتصال)
├── css/style.css         التنسيق
├── js/
│   ├── data/topics.js    تقسيم السورة الموضوعي (يمكن تعديله)
│   ├── data/intro.js     محتوى الفضل والأسماء والمقاصد
│   ├── quran-api.js       الاتصال بواجهة القرآن + المتشابهات
│   ├── srs.js              محرك المراجعة المتباعدة (Spaced Repetition)
│   └── app.js               الواجهة والتنقل بين الشاشات
└── icons/                 أيقونات التطبيق
```

لا يحتاج المشروع لأي عملية بناء (build) أو تثبيت حزم — ملفات ثابتة (HTML/CSS/JS) يمكن رفعها مباشرة.

## النشر على GitHub

```bash
cd nisa-app
git init
git add .
git commit -m "إطلاق تطبيق حفظ سورة النساء"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

استبدل `USERNAME/REPO_NAME` باسم مستخدمك واسم المستودع الذي تنشئه على GitHub.

## النشر على Netlify

**الطريقة الأولى — عبر GitHub (موصى بها، تحديث تلقائي):**
1. ادخل إلى [app.netlify.com](https://app.netlify.com) وسجّل الدخول.
2. اضغط **Add new site → Import an existing project**.
3. اختر **GitHub** واختر المستودع الذي رفعته.
4. اتركه **Build command** فارغًا، و **Publish directory** = `.` (المجلد الجذر، لأن الملفات ثابتة بلا بناء).
5. اضغط **Deploy site**. سيُنشئ لك Netlify رابطًا مباشرًا، ويمكنك لاحقًا تغييره من **Site settings → Change site name**.

**الطريقة الثانية — سحب وإفلات مباشر (بدون GitHub):**
1. اضغط زر التنزيل لملف `nisa-app.zip` المرفق وفكّ ضغطه.
2. ادخل إلى [app.netlify.com/drop](https://app.netlify.com/drop).
3. اسحب مجلد `nisa-app` وأفلته في الصفحة — سينشره Netlify فورًا.

بعد النشر، افتح الرابط على هاتفك واختر **"إضافة إلى الشاشة الرئيسية"** لتثبيته كتطبيق.

## تخصيص التقسيم الموضوعي أو الفترات الزمنية للمراجعة

- لتعديل عناوين المقاطع أو نطاقات الآيات: عدّل مصفوفة `NISA_TOPICS` في `js/data/topics.js`.
- لتعديل فترات المراجعة (بالأيام): عدّل `NEAR_INTERVALS` و `FAR_INTERVALS` في `js/srs.js`.
